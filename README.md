## Project Overview

This project is a simple website that uses HTML, CSS, and JavaScript. The website displays cooking tips when the user clicks a button.

The goal of this assignment was to reorganize the JavaScript code into smaller, more manageable functions with clear responsibilities.

## Tuesday Build Phase

### Changes Made

- Broke the JavaScript into multiple functions.
- Reduced complexity by separating logic into smaller pieces.
- Organized responsibilities into:
  - Event handling
  - Data handling
  - Display logic

### Functions

- `getCookingTips()` - stores and returns available tips.
- `chooseRandomTip()` - selects a random tip.
- `displayTip()` - updates the webpage.
- `handleButtonClick()` - coordinates actions when the button is clicked.
- `setupEventListeners()` - connects the button to the event handler.
